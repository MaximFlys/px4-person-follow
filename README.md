# DFC

ROS 2 workspace for offboard person following. `flight_control_node` reads YOLO detections and publishes PX4 velocity setpoints.

## Layout

```
src/flight_control_node    Python package (this repo)
src/px4_msgs               PX4 message definitions (separate checkout)
```

Colcon discovers packages by walking `src/` and reading each `package.xml`. There is no extra package list. `build/`, `install/`, and `log/` are generated by `colcon build` and are gitignored.

## What the node does

The node name is `flight_node_subscriber`. It runs at 10 Hz.

| Direction | Topic | Type |
| --- | --- | --- |
| Subscribe | `/yolos_detector/detections` | `vision_msgs/Detection2DArray` |
| Subscribe | `/fmu/out/vehicle_attitude` | `px4_msgs/VehicleAttitude` |
| Publish | `/fmu/in/offboard_control_mode` | `px4_msgs/OffboardControlMode` |
| Publish | `/fmu/in/trajectory_setpoint` | `px4_msgs/TrajectorySetpoint` |
| Publish | `/fmu/in/vehicle_command` | `px4_msgs/VehicleCommand` |

Tracking uses the first detection whose class id is `person` or `0`. The image center is treated as `(320, 240)`, so the detector image is 640×480. Horizontal error becomes a yaw rate. Bounding-box height under 120 pixels becomes a forward speed, rotated into the local NED frame with the current yaw. Vertical velocity stays at 0. If that person is missing for more than one second, the velocity and yaw-rate commands go to zero.

After one second of setpoints the node commands PX4 offboard mode and arms. Run it only against a simulator, or on a vehicle that is restrained, until you are ready for that.

`px4_msgs` in this workspace is [PX4/px4_msgs](https://github.com/PX4/px4_msgs) at `ca9895d` (package version 2.0.1, aligned with PX4 `07bac138`). The message package has to match the firmware you fly.

## Build

ROS 2 Jazzy, with `vision_msgs` and `python3-numpy` installed:

```bash
git clone https://github.com/MaximFlys/DFC.git
cd DFC
git clone https://github.com/PX4/px4_msgs.git src/px4_msgs
git -C src/px4_msgs checkout ca9895d26b88ffc14209daf2fc8d8564e51adddd

source /opt/ros/jazzy/setup.bash
colcon build
source install/setup.bash
```

If `src/px4_msgs` is already an empty directory from the committed gitlink, remove that empty directory and run the `px4_msgs` clone again.

## Run

A detector must already be publishing `/yolos_detector/detections`, and a PX4 link must be up (uXRCE-DDS or an equivalent bridge).

```bash
source /opt/ros/jazzy/setup.bash
source install/setup.bash
ros2 run flight_control_node start_flight
```

`start_flight` is the console script for `flight_control_node.flight_node:main`.
